# Тоннель

Две игры с общим визуалом. Выглядят как один проект в двух сборках, но жанрово это разные игры.

- [`a/`](a/) — **Тоннель A**. Столкновения решаются положением: ты непрерывно рулишь по координате X и прыгаешь по Y. Таймингов нет вообще — важно, **где ты**.
- [`b/`](b/) — **Тоннель B**. Препятствие всегда одно, и его надо снять нажатием в окне тайминга, с градациями «идеально / хорошо / поздно / рано / мимо». Руление в стороны на попадание не влияет — важно, **когда ты нажал**.

Общий скин лежит в [`skin.js`](skin.js): палитра, темы заездов и все процедурные рисовалки. Растровых ассетов в мире нет — в `assets/` только элементы интерфейса.

## Локально

```bash
python3 -m http.server 8765
```

- Страница сравнения: [http://localhost:8765](http://localhost:8765)
- Тоннель A: [http://localhost:8765/a/](http://localhost:8765/a/)
- Тоннель B: [http://localhost:8765/b/](http://localhost:8765/b/)

Отладка режима A: `?lvl=6`, `?pose=1` (хитбоксы), `?rig=1` (ручки камеры и позы).

## Как устроена замена визуала

В обоих `render.js` почти каждая отрисовка картинки обёрнута в `if (imgReady(...))` с процедурной веткой рядом. В `src/assets.js` функция `imgReady()` всегда возвращает `false`, поэтому весь код сам уходит в рисование примитивами. Там, где процедурной ветки не было — препятствия, финишная арка, декор, — её дописали поверх примитивов из `skin.js`.

## Рейтинг

Таблица результатов живёт в `localStorage` браузера, у каждого режима свой ключ. Сети нет.
